# Atajos de HyprFrijol

La tecla `Super` es la clave modificadora principal (normalmente la tecla de Windows / Command). Los atajos se definen en `config/hypr/frijol/binds.lua`.

> La chuleta interactiva (`Super + /`) muestra los atajos dentro del escritorio.

## Apps

| Atajo | Acción |
|---|---|
| `Super + Intro` | Terminal |
| `Super + E` | Gestor de archivos |
| `Super + W` | Navegador |
| `Super + C` | Editor de código |
| `Super + X` | Editor de texto |
| `Ctrl + Super + Shift + Alt + W` | Ofimática |
| `Ctrl + Super + V` | Mezclador de volumen |
| `Ctrl + Shift + Escape` | Administrador de tareas |

## Shell y paneles

| Atajo | Acción |
|---|---|
| `Super + Espacio` | Spotlight |
| `Super + Tab` | Vista general de espacios |
| `Super + A` / `B` / `O` | Asistente / panel lateral |
| `Ctrl + Super + A` | Asistente con la ventana actual |
| `Super + N` | Ajustes rápidos |
| `Ctrl + Super + N` | Notificaciones |
| `Super + Alt + N` | No molestar |
| `Super + I` | Ajustes |
| `Super + Shift + I` | Centro de aplicaciones |
| `Super + V` | Portapapeles |
| `Super + .` | Emojis |
| `Super + /` | Chuleta de atajos |
| `Super + M` | Controles de música |
| `Super + G` | Widgets |
| `Super + J` | Mostrar / ocultar barra |
| `Super + Z` | Modo sin distracciones |
| `Super + Shift + G` | Modo juego |
| `Super + Shift + W` | Selector de fondos |
| `Ctrl + Super + Shift + D` | Cambiar claro / oscuro |
| `Ctrl + Super + R` | Reiniciar el shell |

## Voz y dictado

| Atajo | Acción |
|---|---|
| `Super + Alt + D` | Dictado (mantener, soltar para escribir) |
| `Super + Alt + V` | Comando de voz |
| `Super + Alt + M` | Micrófono / dictado |

## Captura y utilidades

| Atajo | Acción |
|---|---|
| `Impr Pant` | Captura (modo interfaz) |
| `Shift + Impr Pant` | Captura de pantalla entera |
| `Super + Shift + S` | Captura |
| `Super + Shift + X` | Copiar texto de una zona (OCR) |
| `Super + Shift + T` | Traducir una zona |
| `Super + Shift + A` | Preguntar a la IA por una zona |
| `Super + Shift + C` | Selector de color |
| `Super + Shift + R` | Grabar / detener |

## Ventanas

| Atajo | Acción |
|---|---|
| `Super + Q` | Cerrar ventana |
| `Super + Shift + Alt + Q` | Forzar cierre (clic en la ventana) |
| `Super + D` | Maximizar |
| `Super + H` | Minimizar |
| `Super + Shift + H` | Restaurar minimizada |
| `Super + F` | Pantalla completa |
| `Super + Alt + F` | Pantalla completa simulada |
| `Super + Alt + Espacio` | Flotante |
| `Alt + Espacio` | Menú de ventana |
| `Super + Shift + Espacio` | Cambiar modo de ventanas |
| `Super + Ctrl + Espacio` | Modo de ventanas de este espacio |
| `Super + P` | Fijar encima |
| `Super + F1` … `F4` | Mostrar / esconder un espacio oculto con nombre (si lo has creado) |
| `Super + Shift + F1` … `F4` | Enviar la ventana a ese espacio |
| `Super + Alt + G` | Agrupar en pestañas / deshacer |
| `Super + Alt + Tab` · `Super + Alt + Shift + Tab` | Pestaña de ventana siguiente · anterior |
| `Super + Ctrl + Alt + flechas` | Meter la ventana en las pestañas de ese lado (las crea si hace falta) |
| `Super + Alt + Shift + G` | Sacar la ventana de las pestañas |
| `Super + Alt + J` | Cambiar división / columna propia |
| `Super + ñ` / `'` | Proporción − / columna más estrecha |
| `Super + ç` / `¡` | Proporción + / columna más ancha |
| `Super + arrastrar` | Mover ventana |
| `Super + clic derecho arrastrar` | Redimensionar ventana |
| `Super + izquierda` | Mitad izquierda / columna anterior |
| `Super + derecha` | Mitad derecha / columna siguiente |
| `Super + arriba` | Maximizar / mitad superior |
| `Super + abajo` | Restaurar / mitad inferior |
| `Super + Alt + W` | Ajustar ventana (Snap) |
| `Alt + Tab` | Cambiar de ventana |
| `Alt + Shift + Tab` | Cambiar de ventana (atrás) |
| `Alt + º` | Ventanas de la misma app |

## Espacios

| Atajo | Acción |
|---|---|
| `Super + 1…0` | Ir al espacio 1…10 de la pantalla activa |
| `Super + Shift + 1…0` | Mover ventana al espacio y seguir |
| `Super + Alt + 1…0` | Enviar ventana al espacio sin seguir |
| `Super + Ctrl + izquierda/derecha` | Espacio anterior / siguiente |
| `Super + rueda` | Espacio / columna siguiente o anterior |
| `Super + S` | Espacio oculto (scratchpad) |
| `Super + Alt + S` | Enviar al espacio oculto |
| `Super + º` | Consola desplegable |

## Pantalla y sesión

| Atajo | Acción |
|---|---|
| `Super + -` / `+` | Lupa (zoom) |
| `Super + L` | Bloquear |
| `Super + Shift + L` | Suspender |
| `Super + Escape` | Menú de energía |
| `Super + Shift + Escape` | Salir de Hyprland |
| `Super + Alt + F1` | Desactivar / reactivar atajos (para máquinas virtuales) |
