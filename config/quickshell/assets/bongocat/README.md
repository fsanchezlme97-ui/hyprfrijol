# Bongo Cat (fuente)

`bongocat.woff` viene de [kitgore/BongoCat](https://github.com/kitgore/BongoCat), la extensión «Bongo Cat» de
VS Code (pixl-garden), con licencia MIT (ver `LICENSE`). La usa `bar/BongoChip.qml`:
`b` izquierda arriba · `d` izquierda golpeando · `c` derecha arriba · `a` derecha golpeando.

Desde la 0.8.5 la barra no pinta la fuente directamente: `bar/bongo.js` calca sus trazos como curvas suaves
(a tamaño de icono la fuente se veía ondulada). La fuente se queda como referencia del dibujo original.
