# Voz sin conversación con la IA — plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** quitar la conversación por voz con Harper, dejar dictado + órdenes de voz (con buscar/leer archivo y una
capa de IA local que solo elige órdenes conocidas) y la voz de Harper como lectora opcional.

**Architecture:** `scripts/hf-voice` gana dos intenciones (`findfile`, `readfile`) y `local_ai()`: Ollama con
salida JSON limitada a `{"orden": <id de ORDENES>, "valor": str}`; cada id tiene una plantilla de frase canónica
que se vuelve a pasar por `parse()`, así el analizador de siempre valida lo que diga la IA. El QML pierde el modo
del micrófono, walkie, fluido y compañero; la barra queda con dos botones.

**Tech Stack:** Python 3 (scripts), QML/Quickshell, Ollama `/api/chat`, Hyprland (lua), kitty + bat.

**Spec:** `docs/superpowers/specs/2026-11-18-voz-sin-ia-design.md`

## Global Constraints

- Todo el texto de la interfaz en español; sin emojis (iconos de `components/Icons.qml`).
- La capa de IA usa siempre Ollama local (`aiEndpoint` si el proveedor es ollama; si no `http://localhost:11434`), nunca `hf-ai chat`.
- La IA nunca produce un comando de shell: solo un id de `ORDENES` y un valor de texto.
- Un solo modelo local para panel y voz: `gemma4:e4b` salvo que un candidato no sea peor (mismos aciertos o más, ninguna trampa fallada) y responda en < 1,5 s en la GPU.
- Voz de Harper: solo lectora, apagada por defecto (`aiVoice: false`).
- Toda dependencia nueva a `install/packages.tsv` (todas las familias).
- Tras QML: `hf-shell refresh` vía `hyprctl dispatch 'hl.dsp.exec_cmd("hf-shell refresh")'`, `dev/lint.sh`, `dev/check.sh`.

## Review Focus

- Frase que la IA traduce a una orden peligrosa inexistente («borra la carpeta de descargas»): debe dar `ninguna` y no ejecutar nada.
- Ollama apagado o lento: la orden no se cuelga más de 3 s; cae al panel escrito.
- «lee notas» con varios archivos `notas*`: abre Spotlight `/notas`, no un archivo al azar.
- Archivo binario o > 2 MB: aviso, no se abre.
- Ajustes viejos (`micMode: "walkie"`, widget «voz» en la barra): la barra arranca sin errores de QML con dos botones.

### Task 2: hf-voice — capa de IA local

**Files:** Modify: `scripts/hf-voice`; `config/defaults/settings.json` (`voiceLocalAI: true`, `voiceLocalModel: ""`)

**Interfaces:**
- Produces: `local_ai(text: str, s: dict, model: str|None=None) -> dict|None` (la intención ya pasada por `parse()`, con `"via": "ia-local"`, o `None` si `ninguna`, error o > 3 s); CLI `hf-voice ai "<frase>" [--model m]` → `{"orden","valor","intent","label","ms","error"}`.
- `ORDENES`: dict id → (descripción para el modelo, plantilla). Ids: reproducir, buscar_youtube, abrir_app, abrir_web, buscar_web, buscar_archivo, leer_archivo, volumen_subir, volumen_bajar, volumen_poner, silenciar, pausa, siguiente, anterior, captura, bloquear, cerrar_ventana, escritorio, temporizador, tarea, modo_oscuro, modo_claro, no_molestar, hora, fecha, orden_propia (valor = frase exacta de una orden de `voiceCommands`), ninguna.
- Modelo: `voiceLocalModel` o, si vacío, `aiModel` cuando el proveedor es ollama, o `gemma4:e4b`.

- [ ] Paso 1: casos en `SELFTEST_AI` (solo con `--ai`, necesitan Ollama): «ponme algo de música tranquila en youtube» → play; «quiero ver qué pone en el archivo de notas» → readfile; «ábreme el editor de código» → launch; «borra la carpeta de descargas» → None; «qué tal estás» → None.
- [ ] Paso 2: implementar. Petición: `POST /api/chat` con `stream:false`, `think:false`, `format` = esquema JSON (`orden` enum de ids, `valor` string), `options:{temperature:0, num_ctx:2048}`, `keep_alive` como `hf-ai` (`ollama_body`). Prompt de sistema corto en español con la lista de ids y descripciones y las órdenes propias del usuario. Tiempo máximo 3 s (`urllib` timeout). La plantilla se rellena y pasa por `parse(..., custom_ok=True)`; si da `unknown`, devuelve `None`.
- [ ] Paso 3: en `execute()` la rama `unknown`: si `voiceLocalAI` no es False y hay respuesta de `local_ai`, ejecutar esa intención (`"via":"ia-local"`); si no, lo de ahora (panel).
- [ ] Paso 4: `scripts/hf-voice selftest --ai` → PASS con gemma4:e4b. Commit.
